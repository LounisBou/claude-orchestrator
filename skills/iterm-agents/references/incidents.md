# Incidents

The observed incidents behind the tab skill's rules, each under the id of the rationale that tells it and the rule it justifies. The rule lives where `SKILL.md` or `references/commands.md` states it; the story that made it a rule is here.

## ITERM-007 — rationale of ITERM-006: the title has a shape

A successor spawned with a typed name once came up as that name in every listing while the house format was nowhere.

## ITERM-021 — rationale of ITERM-020: `move` places what is yours

An orchestrator launched by hand had never measured its own tty, read the listing, took the last tab for its own and moved a stranger's session out from between itself and its agents; the script obeyed, because `move` moved anything it was told to. It now refuses a tty that is neither your own tab nor one of your chain, and `list` marks your row `self`.

## ITERM-026 — rationale of ITERM-025: the launcher names the cause

Never hanging, never reporting what it did not verify, never handing over another terminal: all three were paid for. One right-click left a context menu open in the app, and for four hours every call hung with nothing in any log, found only by sampling the app's main thread.

## ITERM-031 — rationale of ITERM-030: no third rung

A third rung was built, in another terminal, and struck out by the operator's ruling: a session that is not a tab in the window he reads is not an agent he can see, place or close.

## ITERM-037 — rationale of ITERM-036: always name an anchor

Observed: an agent spawned two tabs away from its orchestrator, with a stranger's session between them, because the plain form was read as « fine for an agent ».

## ITERM-072 — rationale of ITERM-055: a close is proved on the process table

`close` once printed « closed 1 session » over a session that kept running for minutes and had to be ended by hand.

## ITERM-073 — rationale of ITERM-058 and ITERM-063: the CLI by absolute path, the launch through a login shell

The first live spawn through this path died instantly and reported a tty belonging to nothing, because the CLI lives in a package manager's bin directory that a bare default PATH does not contain. Before the login shell, no spawned session could run `gh`: the app hands a program run directly a bare default PATH.

## ITERM-074 — rationale of ITERM-062: the tab is born in the anchor's window

With two windows open, a spawn anchored on a tab of the second once landed at the end of the first — the window in front — and reported success.

## ITERM-075 — rationale of ITERM-064: match on words, never on the glyph

A rotation stands the old agent down and then spends ten seconds bringing up its replacement: a title captured before and compared after is guaranteed to differ, and the guard written to make a close unambiguous refused every rotation instead.

## ITERM-076 — rationale of ITERM-070: a hidden pane is still a session

Before hidden panes were listed, a hidden agent was unfindable and unclosable while `ListAgents` showed it alive.
